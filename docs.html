// Elevator Pitch

«not_found» — FPS ближнего будущего с параллельной кампанией двух протагонистов: оператора ЧВК на службе государства и нетраннера, защищающего информацию и подрывающего систему изнутри. Миссии одной стороны зеркалят и переворачивают точку зрения другой. Цель по времени: ~5–7 часов суммарно (кампания как «Call of Duty на один вечер») + быстрый соревновательный мультиплеер 6v6 с классами, прогрессией и killstreaks в духе CoD4 / MW2 / Black Ops.

Design Pillars
1. ОЩУЩЕНИЕ СТРЕЛЬБЫ — каждый выстрел должен чувствоваться: отдача, звук, хитмаркеры, реакция врагов 2. 2. Философия дизайна и навыковое выражение

TTK философия

TTK Philosophy
ЦЕЛЕВОЙ ДИАПАЗОН: 200–400ms < 150ms: «Реакция невозможна» — игрок не успевает среагировать. Ощущение: «меня убивают из ниоткуда». Неудовлетворительно. Пример: некоторые конфигурации в MW2019 на релизе. 200–400ms: «Золотая зона» — реакция возможна, но требует мастерства. Прицел важен, но позиционирование тоже решает. Пример: CoD4, MW2 (2009), Valorant. > 500ms: «Позиция важнее прицела» — бьют долго, можно убежать. Снижает навыковое выражение стрельбы. Пример: Battlefield (намеренно), PUBG. Наш выбор: 250–350ms для AR (4–5 пуль при 800 RPM)

4. Основные механики

Передвижение

Movement System

Система стрельбы (КЛЮЧЕВАЯ)

️ КРИТИЧЕСКИ ВАЖНО

Стрельба — это ДНК игры. Если стрелять неприятно, ничто другое не спасёт проект. Каждый аспект системы стрельбы должен быть отполирован до идеала.

Aiming System
Hip-fire (от бедра) — большой разброс, быстрая реакция ADS (Aim Down Sights) — точно, но медленнее движение Время входа в ADS зависит от оружия (150–350ms) Чувствительность ADS отдельно настраивается
Recoil System
Визуальная отдача — камера дёргается вверх и в стороны Паттерн отдачи — у каждого оружия свой уникальный рисунок Первые 3–5 пуль — предсказуемый паттерн (можно выучить) Дальше — нарастающий случайный разброс Возврат прицела после прекращения стрельбы (0.3–0.5 сек) Реализация: UCurveVector* RecoilPattern — кривая отдачи Каждый кадр стрельбы сэмплируется точка на кривой + случайный разброс, увеличивающийся со временем
Ballistics
Hitscan до 50 метров — мгновенное попадание (Line Trace) Projectile свыше 50 метров — для снайперских винтовок Damage falloff — урон падает с расстоянием (UCurveFloat) Penetration — пробитие тонких стен, зависит от калибра Нет bullet drop для автоматов/пистолетов (упрощение)
Hit Feedback
Хитмаркер — белый крестик + звуковой щелчок Хитмаркер убийства — красный крестик + другой звук Хедшот — увеличенный маркер + уникальный звук «дзинь» Направление урона — красные дуги на экране Hitzone множители: ├── Голова: x1.5 ├── Верхний торс: x1.1 ├── Нижний торс: x1.0 ├── Конечности: x0.8 └── Через стену: x0.5–0.7

Здоровье и урон

Health System
100 HP у всех игроков Авторегенерация — начало через 5 сек после последнего урона Скорость регенерации: 20 HP/сек Визуальная индикация: кровь на экране, звук сердцебиения Направление урона: красные дуги показывают откуда стреляют Мгновенная смерть при 0 HP (нет Last Stand) TTK (Time to Kill) — КРИТИЧЕСКИ ВАЖНО: ├── Идеальный TTK: 200–400ms (как в CoD4/MW2) ├── Автоматы: 3–5 пуль для убийства ├── Снайперки: 1 пуля (торс/голова) ├── Дробовики: 1 выстрел вблизи, 2–3 на средней дистанции └── Пистолеты: 4–6 пуль

5. Игровой отклик (Game Feel / Juice)

Философия CoD-школы: каждое действие должно иметь аудиальный, визуальный И тактильный отклик. Отсутствие любого из трёх слоёв разрушает ощущение от игры, даже если механика технически работает правильно.

Hitstop — стоп-кадр на попадании

Hitstop Implementation
// Дилатация времени при подтверждённом попадании void ApplyHitstop(EHitType HitType) { float Duration = 0.0f; switch (HitType) { case EHitType::BodyShot: Duration = 2.0f / 60.0f; break; // 2 кадра case EHitType::Headshot: Duration = 3.0f / 60.0f; break; // 3 кадра case EHitType::KillShot: Duration = 4.0f / 60.0f; break; // 4 кадра } // Замедляем только жертву и её эффекты UGameplayStatics::SetGlobalTimeDilation(World, 0.05f); GetWorld()->GetTimerManager().SetTimer( HitstopTimer, [this]() { UGameplayStatics::SetGlobalTimeDilation(World, 1.0f); }, Duration, false); }

Правило трёх слоёв: если убираешь любой из трёх (звук, визуал, тактиль) — игроки жалуются что «оружие не ощущается». Это доказано плейтестами CoD4, MW2. В нашем проекте тактильный слой (вибрация) обязателен даже на KB&M через слабую тряску камеры — «tactile proxy».

6. Ощущение игрока — Психология и эмоциональный дизайн

Игровой отклик (Section 5) — это тактильный слой. Ощущение игрока — это психологический слой. Один отвечает за то, как чувствуется выстрел. Другой — за то, как чувствуется вся сессия. Это разные уровни проектирования, и игнорировать второй — значит строить дом без фундамента.

Типы игроков — адаптированная таксономия Бартла для FPS

Player Archetype Model
УБИЙЦА (Killer) ~30% ├── Мотивация: доминировать над другими людьми ├── Что ценит: высокий K/D, killstreaks, нагибать в клиппы ├── Боится: проигрывать публично, выглядеть слабо ├── Дизайн-решение: killfeed, MVP-экран, Prestige значки └── Ошибка: если он доминирует без счётчика → остальные уходят ДОСТИГАТЕЛЬ (Achiever) ~35% ├── Мотивация: выполнять задания, собирать прогресс ├── Что ценит: разблокировки, камуфляжи, уровни оружия ├── Боится: потерять прогресс, невидимого прогресса ├── Дизайн-решение: видимые XP-бары, ачивменты, счётчики └── Ошибка: скрытый прогресс — Achiever теряет мотивацию СОЦИАЛИСТ (Socializer) ~25% ├── Мотивация: общаться с людьми, играть с друзьями ├── Что ценит: голосовой чат, группы, история отряда ├── Боится: играть одному, молчаливого лобби ├── Дизайн-решение: пинг-система, pre-game лобби чат └── Ошибка: нет причин играть с одними и теми же людьми ИССЛЕДОВАТЕЛЬ (Explorer) ~10% ├── Мотивация: понять систему, найти оптимальное ├── Что ценит: deep stats, meta-анализ, скрытые механики ├── Боится: непрозрачных систем, случайности без объяснения ├── Дизайн-решение: подробная статистика, VOD-replay └── Ошибка: прозрачная игра vs. экономика тайны

Тилт и антифрустрационный дизайн

Tilt Theory & Frustration Prevention
ТИЛТ = кумулятивная фрустрация → иррациональные решения Механизм тилта: Смерть₁ (нормально) → Смерть₂ (неприятно) → Смерть₃ (злость) → Смерть₄ (бег в лоб) → Смерть₅ (rage quit) ТРИГГЕРЫ ТИЛТА: ├── «Несправедливая» смерть (lag, читер, спаун-трап) ├── Невозможность отыграться (команда не слушает) ├── Невидимый прогресс (умираю, но не учусь) └── Публичный провал (внизу таблицы, все видят) АНТИФРУСТРАЦИОННЫЕ СИСТЕМЫ: ├── Killcam / смерть-повтор: ВСЕГДА показывает угол врага │ → «Ах, он был ТАМ» → обучение, не слепая злость ├── Mercy timer: 5+ смертей подряд → безопасный спаун ├── XP при смерти: ассист, «смерть с уроном» дают XP │ → нет «бесполезной» смерти, всегда есть прогресс ├── «Смягчённый ранговый дроп»: серия поражений → меньший │ штраф после 3-й потери подряд (RP decay smearing) └── Скрытая статистика поражений: показываем достижения, не «ты проиграл 12 раз за вечер»

Пиковые моменты — архитектура «историй внутри матча»

Peak Moment Design
ПРИНЦИП ПИКОВОГО ОПЫТА (Peak-End Rule): Игроки запоминают матч не в среднем — они запоминают ПИКОВЫЙ МОМЕНТ + КАК МАТЧ ЗАКОНЧИЛСЯ. Хороший матч с плохим финалом → «плохой матч» в памяти. Средний матч с одним epic-моментом → «крутой матч». ТИПЫ ПИКОВЫХ МОМЕНТОВ (все должны встречаться часто): 🎯 «КЛАТЧ» — 1 против N в напряжённой ситуации Дизайн: S&D без респауна → каждый раунд может дать клатч 🔥 «KILLSTREAK» — серия убийств без смерти Дизайн: звук нарастает с каждым убийством, "Double Kill!", "Triple Kill!" голосовой announcer → вербальное подтверждение достижения 🔄 «КАМБЭК» — команда проигрывает, но побеждает Дизайн: режим без очков Domination при 0:2 — сохраняет математическую возможность всегда 💀 «EPIC DEATH» — красивая смерть, которую хочется смотреть Дизайн: killcam всегда доступен, sharing кнопка в killcam «ИСТОРИЯ МАТЧА» = набор таких моментов: └── Цель: минимум 1 пиковый момент за 10 мин для 80%+ игроков Метрика: session replay survey — «был ли момент, который ты хочешь рассказать другу?» → да > 70%

Игрок управляет вручную 30 сек. Пулемёт + ракеты. Уязвим для стрелкового оружия.

Философия дизайна Killstreak'ов

Killstreak — это не просто награда. Это архитектурный инструмент: управляет темпом матча, создаёт переломные моменты, и формирует «истории» внутри раунда. Без грамотного дизайна превращается в систему «богатый богатеет».

Killstreak Design Principles
ПРИНЦИП 1: КАЖДЫЙ KILLSTREAK ИМЕЕТ КОНТРИГРУ ├── 3K БПЛА → сбивается 1 выстрелом из РПГ / Stinger ├── 5K Артиллерия → нет прямой контригры, но: задержка 2сек = время уйти ├── 7K Вертолёт → сбивается 2 ракетами, выходит из строя на 30 сек └── ПРАВИЛО: если killstreak нельзя игнорировать И нельзя уничтожить → он сломан. Хотя бы одна дверь должна быть открыта. ПРИНЦИП 2: БЮДЖЕТ СИЛЫ (Power Budget) ├── Kill-стоимость = мера «силы» ├── 3K = информация (мягкая сила) ├── 5K = зональный урон (средняя сила) ├── 7K = активное преследование (высокая сила) └── Нелинейность намеренна: 9K НЕ = 3× мощи 3K. Скачок. Теория дизайна режимов

Каждый режим — это уникальный контракт с игроком: обещание определённого ритма, напряжения и истории раунда. Смешивать эти ритмы нельзя — карта для S&D работает иначе, чем карта для TDM.

Mode Psychology
TEAM DEATHMATCH — «Свободный джаз» ├── Нет объектива → всё действие везде одновременно ├── Психология: личная статистика важна (K/D виден всем) ├── Ритм: высокий, постоянный, без пиков и пауз ├── Опасность: «фермерство» (grind) убийств без напряжения └── Дизайн-решение: таймер 10 мин, не счёт — создаёт давление финала DOMINATION — «Перетягивание каната» ├── 3 точки создают «3 истории» внутри раунда ├── Психология: позиция важнее убийств; можно выиграть не выходя в топ K/D ├── Ритм: пульсирующий (атака/удержание/контратака) ├── Опасность: «черепаха» — команда сидит на своих 2 точках └── Дизайн-решение: очки только при КОНТЕСТЕ (не 3:0) SEARCH & DESTROY — «Шахматы» ├── 1 жизнь = максимальное давление каждого решения ├── Психология: смерть имеет цену → тактика, не агрессия ├── Ритм: медленный, нарастающий, с катарсисом в финале раунда ├── Опасность: «кемперство» — пассивная игра выгодна технически └── Дизайн-решение: таймер 2 мин + звуковой сигнал каждые 30 сек FREE-FOR-ALL — «Хаос» ├── 8 игроков, нет команд → постоянная угроза со всех сторон ├── Психология: параноидная осведомлённость, ни одному союзнику нет ├── Ритм: хаотичный, высокий адреналин └── Дизайн-решение: карты всегда меньше — плотность контакта выше

Карты мультиплеера

Map Design Philosophy
КАРТА 1: «ЗАВОД» (средняя, все режимы) ├── Заброшенный промышленный комплекс ├── Классические 3 линии: │ ├── Левая: открытая, длинные дистанции (снайперы) │ ├── Центральная: здание завода, CQB │ └── Правая: переулки, средняя дистанция ├── Вертикальность: 2 уровня (крыши, лестницы) └── Референс: Crash (CoD4) + Firing Range (Black Ops) КАРТА 2: «ПОСОЛЬСТВО» (малая, TDM/S&D) ├── Городской квартал, посольство в центре ├── Симметричная, плотная ├── Много дверей, окон, углов ├── Вертикальность: 3 уровня (подвал, этаж, крыша) └── Референс: Vacant (CoD4) + Nuketown (Black Ops) КАРТА 3: «ПЕРЕВАЛ» (большая, Domination/Hardpoint) ├── Горная дорога, блокпосты, деревня ├── Асимметричная, разнообразный рельеф ├── Открытые зоны + здания деревни ├── Вертикальность: естественная (холмы, скалы) └── Референс: Overgrown (CoD4) + Afghan (MW2) КАРТА 4: «ПОРТ» (средняя, все режимы) ├── Ночной грузовой порт, контейнеры ├── Лабиринт контейнеров + открытые причалы ├── Динамическое освещение (прожекторы, неон) ├── Вертикальность: контейнеры как платформы, краны └── Референс: Shipment (CoD4, но больше) + Terminal (MW2)

Теория потоков карты и бюджет линий обзора

Карта — это система управления движением и информацией. Каждый коридор — «обещание контакта». Каждая стена — «разрешение на безопасное движение». Весь дизайн сводится к управлению этими двумя ресурсами.

АНАЛИЗ ПОТОКА «ЗАВОД» (схема): [SPAWN A]──────────────────────────────[SPAWN B] │ \ / │ │ ╔══╧════════════════════╧══╗ │ │ ║ ОТКРЫТЫЙ ЦЕНТР ║ │ │ ║ (высокий риск, ║ │ │ ║ высокая награда) ║ │ │ ╚════════════════════════╝ │ │ / \ │ [ЛИНИЯ 1] [ЛИНИЯ 3] Дальние дистанции CQB коридоры (снайпер-зона) (SMG-зона) │ │ ────┼──────────[B]──────────┼──── СПОРНАЯ ТОЧКА
Sightline Budget Theory
БЮДЖЕТ ЛИНИЙ ОБЗОРА (Sightline Budget): Каждая позиция имеет «долг» — чем дальше видишь, тем уязвимее ты. ХАРДКОРНЫЙ УГОЛ: видит 40м+ → уязвим сзади + контр-угол 90° ПАУЭР-УГОЛ: видит 2+ входа в комнату → уязвим от гранат/дыма ИНФОРМАЦИОННЫЙ: видит вход/выход зоны → уязвим тому, кто его читает ПРАВИЛО: ни одна сильная позиция не удерживается 1 игроком против 2+ — минимум 3 контр-угла обязательны МЕТРИКА «Убийства из позиции»: Если 1 угол даёт >25% убийств на карте → он сломан. Цель плейтеста: равномерное распределение по зонам ±15%
Spawn Protection Theory
СПАУН-ТРАП — главный враг дизайна карт: Спаун-трап = враги контролируют все маршруты выхода из спауна. Игрок умирает прежде чем «входит» в карту. ИНДИКАТОРЫ СПАУН-ТРАПА: ├── Среднее время до смерти после спауна < 3 сек ├── K/D разрыв > 4:1 между командами └── Spawn flip не происходит (или непредсказуем) ЗАЩИТА: ├── «Спаун-пузырь»: радиус 20м без позиций врага ├── Минимум 2 маршрута выхода из зоны спауна ├── Spawn flip: все 3+ выхода заблокированы → спаун на другом конце └── «Mercy timer»: 5+ смертей подряд → приоритет безопасного спауна

Progression System
УРОВНИ ИГРОКА: 1–55 ├── Каждый уровень разблокирует оружие/перк/killstreak ├── XP: убийства (100), победы (500), задачи (200) ├── Prestige: после 55 → сброс + значок └── 5 уровней Prestige УРОВНИ ОРУЖИЯ: 1–30 (для каждого оружия) ├── Разблокировка модификаций ├── XP за убийства этим оружием ├── Камуфляжи за достижения: │ ├── 50 убийств — базовый камуфляж │ ├── 100 хедшотов — золотой │ ├── Все задания — платиновый │ └── Все оружия платиновые — «not found» (уникальный) └── Визуальные счётчики убийств на оружии СОЗДАНИЕ КЛАССОВ: ├── 5 кастомных классов + 5 предустановленных ├── Основное оружие + модификации ├── Вторичное оружие ├── Летальное снаряжение (граната, мина, C4) ├── Тактическое снаряжение (дымовая, светошумовая, сенсор) ├── Перк 1 + Перк 2 + Перк 3 └── Killstreak 1 + Killstreak 2 + Killstreak 3

Философия JOMO вместо FOMO: мы не используем механики страха упустить (time-limited exclusive cosmetics). Вместо этого — JOMO (Joy Of Missing Out): награждаем за время, которое игрок ПРОВЁЛ в игре, а не наказываем за пропуск. Нет счётчиков «осталось 2 часа!», нет эксклюзивов навсегда. Это строит долгосрочное доверие, а не краткосрочные всплески активности.

12. Кампания — сингл-плеер

Объём и опоры дизайна

Цель по времени: ~5–7 часов суммарно при прохождении обеих параллельных линий (ЧВК и нетранеры). По подаче это не RPG-марафон, а классический «боевик» в духе CoD: плотные боевые блоки, скриптовые вехи, минимум филлерных пробежек.

Titanfall 2: каждая миссия имеет свой центральный геймплейный повод (новая механика или резкая смена режима), который вводится и отрабатывается без затягивания.

Black Ops 2: параллельные точки зрения, пересечения и последствия — игрок видит одни события глазами двух сторон.

Логлайн и конфликт

В вымышленном мегаполисе ближайшего будущего государство и частный сектор срослись с тотальным цифровым контролем. Вы играете за оператора ЧВК «Периметр», выполняющего контракт стабилизации — и за нетраннера, который выносит наружу то, что система хочет стереть. Одни и те же узлы сюжета показываются с противоположных сторон; финальная картина складывается только после обеих линий.

Структура и математика времени

Две линии по 6 миссий (рабочая черновая сетка). Целевое среднее 25–35 минут «чистого» времени на миссию → ~6 ч после суммирования + кат-сцены и провалы ≈ 5–7 ч total.

ИИ врагов (Combat AI)

AI Behavior
Поведение (Behavior Trees): ├── Укрытия (cover system) — враги прячутся за объектами ├── Фланговые манёвры (если игрок стоит на месте >10 сек) ├── Гранаты (бросают, если игрок долго за укрытием >15 сек) ├── Отступление (при потере 70% отряда) ├── Подавление (стреляют очередями, не давая высунуться) └── Коммуникация (кричат команды друг другу) Типы врагов: ├── Боевик (базовый) — АК, средняя точность ├── Снайпер — стоит далеко, лазерный прицел виден ├── Штурмовик — бежит на игрока, дробовик/SMG ├── Пулемётчик — стационарная позиция, подавление ├── Гранатомётчик — RPG, стреляет по укрытиям └── Элита — больше HP, лучшая тактика Сложность: ├── Лёгкая: неточная стрельба, мало HP, медленная реакция ├── Нормальная: базовый баланс ├── Сложная: точная стрельба, больше врагов, фланги └── Реализм: 1–2 пули убивают, нет HUD, нет регенерации

15. MetaSounds — Аудиоархитектура

Каждое оружие имеет собственный граф MetaSound Source. Это процедурная аудиосистема — не статичные файлы, а узловой граф, который генерирует звук в реальном времени с учётом дистанции, окружения и состояния игры.

17. Системы рендеринга UE5

Детальная спецификация рендер-фич движка с разбивкой по пресетам качества. Каждая фича имеет четкие границы применения — что рендерится через Nanite, где работает Lumen и когда включаются Virtual Shadow Maps.

Nanite — виртуализированная геометрия

Nanite — область применения
✅ ИСПОЛЬЗУЕТСЯ: ├── Статические меши окружения (здания, обломки, реквизит) ├── Высокополигональные архитектурные детали └── Импортированные скульпты (камни, колонны) ❌ НЕ ИСПОЛЬЗУЕТСЯ: ├── Скелетные меши (персонажи, оружие в руках) ├── Фолиаж (трава, листья) — только Hierarchical Instanced Static Mesh ├── Полупрозрачные меши (стёкла, частицы) └── Меши с vertex animation (вода, ткань)
